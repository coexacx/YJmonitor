# 0.10.3 部署变更

- 新安装只输入站点名称，管理员 admin 的密码自动随机生成，结束显示 IP:端口。
- 自动部署只负责程序、系统用户、私有状态与 systemd；Nginx、HTTPS、证书续期全部改为手动文档。
- 新增 yuji-probe 终端菜单：版本、状态、地址，更新、服务控制、日志、备份、首次设置入口、二步验证恢复、回退及保留数据卸载。
- native -web 支持 HTTP 入口。HTTP 与 HTTPS 使用不同会话 Cookie，HTTPS 保持 Secure 和 __Host 前缀；Host、Origin、CSRF 和登录限制继续生效。
- 初始 HTTP 模式拒绝 Agent 接入及终端功能；配置 HTTPS 后继续使用原来的 WSS 协议、认证与密钥。
- 既有手动部署升级不更改服务文件、监听地址、站点数据或 Nginx 配置；旧 PHP 网关模式的回环限制保留。

部署说明：[Linux 一键安装](Linux一键安装.md) · [反向代理](反向代理.md)。
