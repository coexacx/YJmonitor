# Rust 0.11.4 验收记录

主控 0.11.4；Agent 0.2.3，协议与 Agent 二进制不变。安装与反向代理方式不变。验收日期：2026-10-08。

## 本版范围

- 服务器 → 服务器管理：全部 / 在线 / 离线、名称 / IP 搜索、分组 / 供应商 / 到期组合筛选，最后上报、离线持续时长及连接排查摘要。
- 版本管理：批量 Agent 升级、两个并发名额、持久化任务、进度刷新及失败重试，保留单台回退和迁移重试。
- 服务器上限统一为 1000，包含新建、启动加载、加密备份恢复、批量请求及排序；管理与版本列表每页 50 台，看板每页 60 台。
- 管理接口授权后的序列化缓存、隐藏看板停止重复绘制、同一 NAT 后的合法 Agent 独立限速、主控文件描述符容量。修复重复检查新版时叠加更新按钮。

## 功能与安全检查

- 100 项 Rust 单元测试、3 项 SSH 集成测试通过，Clippy 零警告；22 项前端测试通过。
- 浏览器使用真实管理员登录后隔离测试响应，覆盖组合筛选、IPv6、HTML 文本安全渲染、待接入、空状态、刷新焦点、320 / 390 像素手机布局、亮暗主题、任务进度、失败重试及千节点跨页搜索 / 全选。
- 后端覆盖未登录、CSRF、近期密码 / 二步验证、重复 / 非法 / 超限 ID、部分成功、重复提交、任务冲突、落盘失败、最多两个执行名额和重启恢复。
- 1000 节点加历史移除任务的启动回归通过；已移除节点的无关联任务 / 旧凭据会回收，避免历史记录挤占备份额度。1000 个节点的加密备份解包通过，第 1001 台新建或批量请求拒绝；同一来源的 1000 个合法令牌允许接入，错误令牌和重复连接仍受限制。
- 隔离 HTTP 主控加载 1000 台和 2000 条审计记录：64 次管理员列表请求、16 并发均成功；1000 台排序和批量请求成功到达业务验证；超大请求体返回 413；离线节点全部拒绝升级。额外 160 次突发请求中 113 次按限速返回 429，无意外状态。
- 公开 API 未包含 SSH IP、供应商、私有备注、健康摘要和升级任务。
- 真实测试节点通过页面提交批量任务，经 SSH 主机指纹与发行签名验证完成安装，重新上线并持续上报；SSH 命令输出、独立文件通道读取 /etc/os-release、关闭会话正常。生产节点没有被批量重装。
- 测试站和生产站均已更新到 0.11.4，原有 1 / 22 条节点记录、账户、主密钥、节点凭据、站点与 Telegram 设置经摘要核对保持一致，保留 0.11.3 回退。两站的服务器筛选、排查信息、版本管理和 11 个后台功能区通过浏览器检查，无 JavaScript 异常。
- amd64 / arm64 静态主控编译完成；ARM64 未做真机运行测试。
- 发行包通过 Ed25519 清单验签、SHA-256、架构、逐文件源码一致性、路径及私有内容检查。Gitleaks 命中仅限经逐项确认的 SHA256SUMS.json 文件摘要误报，没有未解决的凭据命中。
- npm audit 0 告警；Cargo Audit 有 1 项既有 RUSTSEC-2023-0071（rsa），没有新增依赖。本项目受管私钥使用 Ed25519，未调用受影响的 RSA 私钥操作；不能把扫描表述为没有任何漏洞，详见 [安全说明](RUST-SECURITY.md)。

## 1 核 / 1 GB 最低配置验证

在开发机上将主控与独立 Nginx 共同置于 CPUQuota=100%、MemoryMax=768 MiB 的 cgroup，主控自身上限 512 MiB，禁用本测试应用的 Swap，保留 256 MiB 系统预算。压测工具在独立 cgroup，未计入应用占用。宿主 CPU 为 Intel Xeon E7-4830 v3 @ 2.10GHz，KVM。

1000 个模拟节点由同一 NAT 来源建立 WSS，每秒上报一次，每台含一块网卡、一块磁盘和 CPU / 内存 / Swap 指标；50 个看板客户端每 5 秒刷新。完成预热后测量 60 秒：

| 指标 | 结果 |
| --- | --- |
| 最终在线 / 最新样本对齐 | 1000 / 1000 |
| 测量期间上报样本 | 60051 |
| 看板请求成功 / 失败 | 600 / 0 |
| Agent 异常断线 / OOM | 0 / 0 |
| 主控 CPU 平均 | 单核 33.4% |
| Nginx CPU 平均 | 单核 22.0% |
| 合计 CPU 平均 | 单核 55.4% |
| 主控 RSS 峰值 | 41.9 MiB |
| 应用整体 cgroup 内存峰值 | 160.9 MiB |
| 看板响应 P50 / P95 / 最大 | 173.1 / 269.2 / 370.1 ms |
| 主控 / Nginx 最大文件描述符 | 1011 / 2111 |

amd64 主控二进制 14.1 MiB；完整安装包的文件内容约 42 MiB，生产程序目录实际占用约 48 MiB。10 GB 系统盘可作为轻量 Linux 的部署目标；操作系统、Nginx、日志、备份和更新回退空间另计，更新前建议至少 1 GB 空闲。无需在部署服务器安装 Rust、Node.js、数据库或 PHP。

本次未新建独立的 1 GB 内存 / 10 GB 磁盘虚拟机。这是限额下的短时模拟上报与看板测试，没有同时运行大量 SSH 会话或大文件传输，不能替代长期稳定性验证。看板响应平均约 0.75 MiB，网络带宽需与访问量匹配。详细指标见 [performance-0.11.4.json](performance-0.11.4.json)，Nginx 连接容量配置见 [反向代理文档](反向代理.md)。
