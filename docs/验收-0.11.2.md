# 0.11.2 功能与安全验收

本版使用主控 0.11.2、Agent 0.2.3，独立 Rust 仓库更名为 coexacx/YJmonitor。测试在 Debian 开发环境及专用测试节点执行，PHP 版未纳入本轮界面修改。

## 功能

- SSH 重装后展示新旧主机指纹，由管理员明确确认；取消、过期、其他登录或并发指纹变化不能替换信任记录。
- 管理员用户名可在账户安全修改，验证当前密码，保留二步验证与恢复码，撤销旧登录。
- 终端底部为文件、命令、链路；常用命令按两列展示名称和运行按钮。移除空工具栏，保留手机快捷键和粘贴入口。
- 模态窗口滚动时保持主题模糊、隐藏滚动条；终端历史仍可滚动，到达边缘后背景不滚动。
- 管理员服务器详情的硬件、系统、通讯延时、运行时间和进程与服务入口统一对齐。
- 独立群组通知仅发送上线、离线、恢复和管理员主动发起的测试；验证机器人在群组中的管理员权限，保留原接收人设置。
- 安装脚本自动准备低权限服务用户和私有目录，sudo YJ 为管理菜单入口，旧命令保留为兼容别名。

## 浏览器与节点实测

隔离 OpenSSH 实例实际轮换三组 Ed25519 主机密钥，浏览器验证首次信任、重装确认、取消、CSRF、跨登录、过期检查和并发更改，确认错误主机密钥不能收到密码。隔离实例故意禁用密码登录，不在那里安装 Agent。

10 组集成流程通过；另覆盖 5 个主题 × 2 种明暗模式 × 2 种屏幕宽度，共 20 种组合，检查持续模糊、隐藏滚动条、硬件网格和移动端排列。

真实节点上完成 8 组浏览器终端检查：执行常用命令、历史滚动、文件导航和编辑、手机命令与粘贴、关闭标签撤销会话、文件连接单独恢复，以及整个终端异常断线后自动恢复原 Shell。

直接 WSS 协议检查覆盖其他登录不能接管 Shell / 文件会话、重复文件连接被拒绝、文件连接不能执行 Shell 输入、主动关闭不能恢复，并验证原合并文件协议的 8 MiB 下载与并发输入，下载完成校验摘要。

## 扫描说明与边界

主控 Cargo 审计保留 RUSTSEC-2023-0071：上游 rsa 私钥操作时序告警暂无可用修复版本。当前自动管理的私钥采用 Ed25519，SSH RSA 主机公钥验证不属于受影响的 RSA 私钥操作；项目仍明确披露该依赖，未将其标记为已修复。

Bandit 全量扫描 ops 报告 6 项中等级、44 项低等级提示，无高等级提示。中等级项经检查分别涉及三个公开程序 / 工具文件及目录的 0755 权限、安装时按要求监听 IP:端口、固定 GitHub HTTPS 下载地址和回环健康检查。低等级主要是参数数组子进程调用、固定路径操作与测试断言。它们属于需核对上下文的静态规则提示，未按数量直接等同于可利用漏洞；原始报告保存在私有验收目录。

群组权限解析、事件过滤、独立重试顺序、旧通知设置兼容，以及文件连接的父会话、登录版本、节点归属、重复连接和过期清理均有回归覆盖。Bot Token 不写入源码、安装包或操作记录。

ARM64 为交叉编译和 ELF / 架构校验，没有在本轮进行 ARM 真机测试。安全扫描和快速压测不能保证不存在未知漏洞，或替代部署者自己的长期运行观察。
