# Rust 版终端工作区（0.11.2 更新）

本次调整仅用于独立 Rust 版。PHP 版的界面不随此版本修改。Agent 协议保持兼容，现有 0.2.2 Agent 无需重新安装。

## 连接与布局

点击服务器的 SSH 按钮会自动连接。顶栏显示当前打开的会话，绿色圆点表示连接可用，灰色圆点表示断开；点加号选择在线服务器并打开新连接，最多同时使用 4 个标签。关闭标签后，序号按当前打开的标签重新排列。

右上角为展开、关闭。会话标签下方直接显示终端工作区；关闭标签的 × 会结束对应 SSH shell。临时网络中断自动进行有限次数的重试并尝试恢复原会话，不会重复执行输入；重试耗尽后可关闭标签并重新新建连接。常用命令移至底部命令页，手机快捷工具栏保留粘贴入口。

终端背景为深蓝，使用 13px 等宽字体，优先选择 Windows 上的 Consolas；其他系统依次使用可用的等宽字体。行高、默认浅色文字、光标和选区沿用原版，命令的 ANSI 颜色继续由终端解释，低对比颜色自动提高可读性。侧边栏、顶部和底部使用白色，其他布局沿用原有控件样式。站点主题、深浅模式、季节背景和上传主题不再改变终端配色。手机显示 Ctrl、Tab、Esc、方向键等快捷键，桌面隐藏该行，可按 Ctrl / ⌘ + Shift + F 查找终端内容。鼠标滚轮和手机滑动仍可查看本地终端输出历史。

## 左侧监测与磁盘

打开终端即显示侧栏，不提供隐藏按钮，只能拖动调整宽度；手机也保留侧栏，并使用适合窄屏的宽度范围。侧栏展示连接 IP、运行时间、1/5/15 分钟平均负载、CPU 和内存占用；仅启用 Swap 的节点显示交换区。

资源条下方展示进程列表，每行包含内存、CPU 和命令名称；点击表头切换 CPU / 内存降序，显示前 10 项。每 5 秒通过现有的独立 SSH 文件连接读取，首次采样的 CPU 显示 —，随后按单核 100% 计算。只读取进程名，不展示可能含敏感参数的完整命令行。切换终端或隐藏页面后暂停读取。

网络图可选择网卡，显示实时上下行速率及累计字节数。第二张图显示主控与 Agent 的通信延时。指标沿用原有的细进度条、字体和配色，更新时平滑过渡；折线按浏览器动画帧平滑移动，仅展示真实采样。每条曲线最多保存 60 个采样点，并按真实时间清理两分钟前的数据。终端打开时暂停背后看板卡片的模糊处理，关闭后自动恢复，不修改站点主题设置。切换终端或隐藏页面会停止该图的动画；启用系统“减少动态效果”时只在数据刷新时更新。

CPU、内存和网络使用现有 Agent 数据；负载与磁盘容量通过独立 SSH 文件连接读取。磁盘区域列出挂载路径和“可用 / 大小”，容量按 B/K/M/G/T 缩写。可用容量使用文件系统报告值，考虑了保留空间，不能简单按总量减已用计算。

点击挂载路径会在底部打开该目录。左侧不再列出目录树，也不递归扫描目录大小。磁盘信息每 15 秒读取，主控缓存 10 秒；仅查询本地文件系统，命令限时 3 秒，输出不超过 32 KiB。无法读取时显示 —，文件浏览仍可使用。

## 底部文件、命令与链路

底部标签依次为文件、命令、链路，连接后默认显示文件列表。进入子目录会替换当前内容；路径栏、上一级、刷新、上传、新建文件和新建目录均保留。命令页每行并排显示两个命令名称，右侧为运行按钮，列之间使用分隔线；脚本内容不在此处展示。链路页显示主控到被控的路由与持续 TCP 连通性。迟到的文件加载响应不会把用户正在查看的命令或链路页切走。

点击文件使用原有在线编辑器，保持 PHP 默认编辑区的深色底板、浅色正文和保存按钮样式；语法高亮、行号、查找输入和光标采用适合深色底板的颜色，不继承白色工具栏的深色文字。保存仍需核对差异并验证远端版本。上传取消不会关闭 SSH 会话。文件浏览、文件传输和交互终端继续使用分离的 SSH 连接。

侧栏宽度和底部高度支持拖动，也支持聚焦分隔条后用方向键调整。设置了最小宽高，防止拖动后信息或终端区域完全不可见。手机键盘展开、视口过低时收起底部区，为命令输入留出空间。

## 路由工具和权限

一键安装器会安装 tracepath。已有手动安装可在主控执行：

Debian / Ubuntu：

    apt-get install --no-install-recommends iputils-tracepath

RHEL / Rocky / AlmaLinux / Fedora：

    dnf install iputils

工具在主控的普通服务用户下运行，不授予原始套接字能力或 root 权限。未安装工具时会显示提示，TCP 检测和 SSH 仍可使用。

路由使用 UDP 探测，最多 16 跳、15 秒，至少缓存 60 秒，同时最多运行 2 个路由任务。主控到节点 SSH 端口的 TCP 检测每 5 秒采样，超时 2 秒。两种检测与浏览器经 WSS/Agent 的终端通道路径不同：某一跳不回复，或节点公网 SSH 被防火墙限制，不等于 Agent 终端已经断开。

接口只接受已登记节点 ID 和当前管理会话拥有、已连接的 SSH 文件会话。需要管理员登录、同源校验及 CSRF 校验；不能提交自定义地址、端口或命令。地址按数值 IP 校验，诊断输出按纯文本渲染，子进程输出、并发、运行时间和缓存数量都有上限。

## 路由 IP 与运营商

每一跳显示响应 IP、运营商、ASN 和延时。公网 IP 的网络归属取自 [RIPEstat Prefix Overview](https://stat-ui.stat.ripe.net/docs/data-api/api-endpoints/prefix-overview.html)，展示 ASN 的登记名称；它可能与机房销售品牌不同。内网及保留地址就地标注，不向外部服务查询。未响应的跳数显示 *；无归属数据、查询超时或配额不足时显示未知，不猜测运营商。

归属信息通过固定 HTTPS 地址查询，不携带面板凭据。主控最多同时发出 2 个请求，每个请求限时 4 秒、响应上限 64 KiB，每分钟至多 60 次、24 小时至多 900 次。成功结果缓存 24 小时，失败缓存 15 分钟；缓存最多 512 个 IP。查询在后台进行，路由 IP、SSH 终端和 TCP 连通性不等待运营商数据。归属查询每轮最多等待 12 秒。API 使用规则见 [RIPEstat 文档](https://stat.ripe.net/docs/data-api/ripestat-data-api)。

## 站点主题性能

各内置主题的滚动与四季动画以 60 Hz 为目标，实际帧率取决于设备和浏览器。看板滚动时暂缓重复模糊计算；打开详情、添加服务器或终端窗口后保持背景模糊。详情和添加服务器窗口隐藏滚动条，仍支持鼠标、触摸和键盘滚动。模态窗口打开期间锁定背景页面，终端滚到输出历史顶部或底部不会继续滚动背后看板。四季仍为每季一分钟，后台或暂停状态停止动画。详情和测试条件见主题开发文档及验收记录。
