# 0.11.5 验收记录

本版修正版本管理和筛选按钮，统一 YJ 部署入口与目录。Agent 协议与二进制仍为 0.2.3。

## 行为

- 版本管理标题统一，升级与回退使用按钮；重置筛选缩为“重置”，桌面及手机不超出页面。
- 主控后台每小时检查正式发布与签名 Agent 清单，管理员登录后自动提示新版；失败明确展示，不误判为最新版。
- Agent 同版、更高版、未知版本、离线、忙碌节点不能重复提交升级。只安装当前主控配套的兼容版本；检测到更高 Agent 发布时提示先更新主控。
- 此区域无需再次输入管理员密码，保留登录、同源、CSRF、签名校验与速率限制。备份和账户安全复核不变。
- 新安装使用 sudo YJ、用户 YJ、/opt/YJ、/var/lib/YJ、/etc/YJ、YJ.service。更新器、菜单、日志、备份及续期服务同步使用新的路径。
- 旧目录的安装保留兼容处理；回退到旧版二进制时保留可用的 YJ 运维脚本。

## 验证

在 Debian 13 开发服务器完成以下验证：

- Rust 107 项单元测试、3 项 SSH 连接测试；前端 25 项、运维脚本 55 项测试通过。Rust Clippy 无警告，脚本语法与 Python 编译检查通过。
- 浏览器覆盖当前版、旧版、更高版、未知版本及离线节点；自动提示、查询失败、重复检查、批量选择和完成后禁用升级正确。320 / 390 / 1024 / 1280 宽度及明暗主题无页面溢出；11 个后台功能区无 JavaScript 异常。
- 实际运行完整签名安装脚本，创建 YJ 用户和私有目录；验证 HTTP 管理员登录、sudo YJ 菜单、服务重启、开机启用、CLI 备份、0.11.4 与 0.11.5 双向回退、回退后菜单可用、卸载保留数据。安装测试使用独立端口，验收后清除测试实例。
- 开发站与生产站均迁移至 /opt/YJ、/var/lib/YJ、/etc/YJ、YJ.service；保留原有域名及监听端口。开发站 1 台、生产站 22 台节点记录及主密钥、管理员认证、节点密钥、站点配置和 Telegram 配置比对一致。
- 开发站实际 Agent 自动重连并持续上报；真实 SSH 命令输出、独立文件通道读取及主动关闭正常。生产站浏览器登录、实时列表、版本检查和 11 个后台功能区通过。
- 真实接口拒绝未登录、无 CSRF、重复/非法节点 ID；同版 Agent 的批量请求不创建任务，单台同版 Agent 和同版主控升级被拒绝。Agent 二进制仍为 0.2.3，本次没有对最新版节点重复安装。
- 主控 amd64、arm64 均交叉构建，核对 ELF 架构、三份签名清单及文件摘要。实际运行验收为 amd64；开机启动检查通过 systemd enable 与实际服务重启验证，没有重启整机。

## 安全检查

- npm audit：0 项告警。RustSec 数据库更新至 2026-10-07，仍有既存的 RUSTSEC-2023-0071（rsa 依赖时序侧信道）告警；没有新增依赖或新增依赖告警。当前管理密钥使用 Ed25519，此告警保留记录，不能据此声称系统不存在任何漏洞。
- 完整安装包做 Gitleaks 扫描和已知测试/生产口令检索；未发现真实凭据。扫描器对 SHA256SUMS.json 的 18 条摘要误报，已逐条与实际文件摘要匹配后排除。
- 完整 ZIP 逐文件核对源码及 SHA-256，核对签名、架构和路径，不含运行状态、私钥、真实口令、node_modules 或构建缓存。
- 审阅重点包括身份验证边界、CSRF、版本比较、防重复升级、签名和下载重定向、检查取消/超时、文件与服务身份迁移、目录权限、旧版回退兼容及同名文件保护。

测试与扫描反映上述版本及场景，不代表对所有环境和未知漏洞的绝对保证。1000 节点低资源容量测试仍参考 0.11.4 验收记录，本次版本检查按主控统一缓存，不逐节点发起 GitHub 请求。
