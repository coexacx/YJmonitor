# Rust 0.11.0 验收记录

验收日期：2026-10-06。范围为独立 Rust 版主控及浏览器终端；PHP 版界面未修改，现有 Agent 0.2.2 协议兼容。

## 界面与真实节点操作

在开发站使用真实 Linux 被控节点完成 20 组浏览器回归，浏览器未记录脚本错误或 HTTP 5xx。覆盖桌面与手机布局、自动连接、标签数和连接状态、固定侧栏、进程 CPU/内存排序、文件系统可用/总量、网卡与通信延时、路由 IP 和运营商、文件导航、编辑核对保存及读取验证、上传取消、调整大小边界、滚轮历史、断开和恢复、查找快捷键、手机按键、关闭会话。

终端优先使用 Consolas 等宽字体，系统没有该字体时使用其他等宽字体；真实 shell 的 ANSI 红、绿、蓝输出分别验证。未打包或下载商业字体。

文件编辑器分别以纯文本和 JSON 验证五种内置主题的浅色、深色模式，共 20 种组合。检查正文、语法高亮、行号、选区、光标及查找输入；采样正文/语法/行号与底色的最低对比度为 7.68:1。保存仍执行差异确认和远端版本校验。编辑区采用原 PHP 默认深色底板和浅色正文，外侧工具栏及监测侧栏保持白色。

默认看板背景下，4 秒图表采样记录 240 次路径更新，约 60 次/秒。此结果仅代表本次测试环境；后台隐藏或标签不活动时停止动画和进程查询，不代表所有设备都能达到固定帧率。

## 功能及权限边界

额外的六组真实协议测试已通过，覆盖跨登录会话的 shell / 文件会话隔离、负载和文件系统返回值、非法参数和已移除动作拒绝、查询缓存、8 MiB 文件下载与并发目录查询及 shell 输入、异常断线恢复同一 shell、手动关闭后不可恢复。文件下载约 19.8 秒，仅为功能检查，不作为网络吞吐基准。

路由接口验证管理员身份、CSRF、节点与已连接文件会话的所有权；未知参数和伪造会话被拒绝。并发重复请求使用缓存。子进程采用固定绝对路径与参数，输出大小、超时和并发均受限；公网归属查询采用固定 HTTPS API，内网地址不对外查询。

Rust 单元及 SSH 保活测试 72 项通过，Clippy 全目标检查通过；前端现有 14 项测试通过；安装/管理脚本语法及 Git 空白检查通过。AMD64 与 ARM64 静态发布二进制均完成编译和 ELF 架构校验，实际运行验证为 AMD64，未把 ARM64 编译成功写成实机运行验收。

## 安全扫描结果与限制

- 本次源码 Gitleaks 扫描未发现泄露，前端 npm 审计为 0 项漏洞。
- Cargo Audit 原始结果仍保留 **RUSTSEC-2023-0071**：依赖 rsa 0.10.0-rc.18 的 Marvin 时序侧信道告警，上游没有已修复版本，未通过忽略规则隐藏。
- 当前程序仅生成和使用 Ed25519 客户端私钥；RSA 用于已有 SSH 服务器的主机公钥验签。按当前代码路径，没有该告警描述的 RSA 私钥运算入口。这是可达性评估，不表示依赖已修复，详细说明见 [安全边界](RUST-SECURITY.md) 与 [RustSec 公告](https://rustsec.org/advisories/RUSTSEC-2023-0071.html)。
- 发布采用现有 Ed25519 签名清单与 SHA-256 校验。生产升级仍由现有更新器完成代码/状态快照和失败回退。

这些结果说明已验证范围内的行为符合预期；不构成不存在未知漏洞或任意设备长期稳定性的保证。

## 主题动画与滚动复测

在实际发布二进制上完成额外 10 组主题检查：缓存画面空闲时不重复绘制、季节交接、春夏秋冬循环、暂停与恢复、页面隐藏处理、减少动态效果偏好、手机及 4K 画布上限、深色配色、滚动后恢复玻璃模糊、反复切换主题释放资源。检查无浏览器脚本错误。

性能条件：同一开发服务器、同一 Chrome 无头浏览器、1440×1000 视口，各场景采样 5 秒。压力场景在浏览器内复制为 12 张卡片，暂停数据刷新以比较渲染开销，不向主控注册模拟节点。统计前台 requestAnimationFrame 回调和帧间隔，短样本可能有约 0.2 帧计数误差，不等同于测量用户显卡最终呈现帧数。

| 12 卡片场景 | 优化前（帧/秒） | 优化后（帧/秒） |
| --- | ---: | ---: |
| 默认主题滚动 | 10.4 | 58.2 |
| 透明玻璃滚动 | 10.4 | 58.8 |
| 简笔画滚动 | 60.2 | 60.2 |
| 二次元滚动 | 12.4 | 59.4 |
| 四季滚动 | 56.0 | 55.8 |
| 四季交接 | 46.6 | 55.4 |

开发站实际 1 张卡片时，四季滚动为 59.2 帧/秒，季节交接为 59.9 帧/秒，交接阶段第 95 百分位帧间隔约 16.7 ms。目标为接近 60 帧；12 卡片压力场景仍可能降至约 55 帧，不承诺任意硬件或自定义样式固定达到 60 帧。

默认、透明玻璃及二次元主题在滚动/短暂卡片过渡时暂停重复的模糊采样，停止后恢复原有玻璃效果。四季保持每季 60 秒、交接 6 秒；单张背景位图预算由 65 万降至 48 万像素，约减少 26%，界面文字和图标分辨率不变。主线程仅在季节交接阶段逐帧混合缓存，平时由浏览器处理镜头与天气运动，隐藏页面或暂停后停止动画。
