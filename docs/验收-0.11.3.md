# 0.11.3：管理员服务器状态筛选

主控 0.11.3，Agent 沿用 0.2.3；部署方式、认证、通信协议与数据格式保持兼容。

## 本版变化
服务器管理增加“全部 / 在线 / 离线”按钮和数量，使用管理员完整节点列表计数。未首次上报的节点归入离线，行内仍标识“待接入”。后台刷新会保留当前选择，并随节点上下线更新结果。空列表提供对应提示。

所有服务器视图保留原有拖动和箭头排序；按在线或离线筛选时隐藏排序，避免不可见节点被意外移动。编辑、移除、SSH 和运行状态入口保留。筛选不会改变看板上的选择，退出登录清除本次选择。

## 验证范围
- 前端现有 16 项回归测试通过；Rust 主控 88 项单元测试及 3 项集成测试通过。
- 浏览器检查真实接口数量，以及在线、离线、待接入、仅管理员可见和空列表的筛选行为。
- 模拟节点恢复后，验证实时计数与列表更新；检查后台轮询和菜单切换后的状态保留。
- 检查键盘焦点、320 / 390 像素手机宽度、亮暗模式与页面脚本错误。
- 对照代码审查管理功能；逐项浏览各管理菜单，建议功能单独记录，未在本版直接实施。
- 正式安装包验证 Ed25519 签名、逐文件 SHA-256、归档路径、amd64 / arm64 架构和敏感信息。

未以模拟上报代替真实服务器故障，也未为筛选测试停机、删除或修改已有节点。ARM64 交叉构建不等于 ARM 真机测试。

## 安全
没有新增管理接口、后台权限、外部依赖或持久化数据字段。名称和数量按 DOM 文本渲染，原有管理员认证及 CSRF / Origin 校验继续生效。

npm 审计无已知漏洞；主控 Cargo Audit 仍报告已披露的 RUSTSEC-2023-0071，详见 [安全边界](RUST-SECURITY.md)。没有新增依赖告警。扫描结果不代表不存在未知漏洞。
